About QuickNotes

QuickNotes is a simple app for saving short notes. It helps you remember ideas and to-dos.

How to use QuickNotes

  1. Type a note.
  2. Click Add.
  3. Read your notes in the list.

Features

  • Quick notes
  • Simple design
  • Keyboard shortcuts

Keyboard shortcuts

Shortcut Action
Ctrl + N New note
Ctrl + S Save note
